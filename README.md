# 天工开物 · 佳兵对决

明代兵器工坊主题的网页卡牌对战 Demo，玩家通过抽牌、重铸与制造兵器对抗电脑掌柜。

## 游玩

使用 GitHub Pages 发布，可在电脑或手机浏览器中打开。点击配方制造兵器，选择手牌进行重铸，每回合最多制造一次。

双方初始声望20；起手5张，自己的回合抽2张，手牌上限7张。火器有30%概率炸炉，可选择损失1点声望或弃2张手牌止损。详细规则见游戏内「玩法说明」。

## 文件

- `index.html`：游戏页面
- `style.css`：桌面与手机布局
- `game.js`：对战规则与AI
- `app.js`：页面交互与动画

无需安装依赖或构建。使用静态HTTP服务器即可本地运行。
