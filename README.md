# 天工开物 · 佳兵对决

明代兵器工坊主题的网页卡牌对战 Demo，玩家通过抽牌、重铸与制造兵器对抗电脑掌柜。

## 游玩

使用 GitHub Pages 发布，可在电脑或手机浏览器中打开。点击配方制造兵器，选择手牌进行重铸，每回合最多制造一次。

双方初始声望10；起手5张，自己的回合抽2张，手牌上限7张。火器有30%概率炸炉，可选择损失1点声望或弃2张手牌止损。详细规则见游戏内「玩法说明」。

## 卡手调整

每回合的重铸机会可指定换取边角料、熬胶缠筋、冶铁钻孔或配比火药，四种目标共用一次机会。选择一张不同名手牌弃置，换得一张目标牌；边角料也可换成工序。换得的牌属于临时牌，使用或弃置后移除，避免洗牌导致牌库无限增长。

AI使用相同的换牌规则，超限弃牌优先保留能制造的配方。制造按钮会列出具体缺少的材料或工序。

## 手牌与战斗反馈

手牌采用与声望区一致的深青漆面、古金细框与暖白牌名。十一种材料、工序与边角料各有对应的物品插图；材料、工序、通用牌分别以青玉、暖铜、古金色签区分。桌面保留三个独立分区，手机以紧凑两行展示图片与名称。对方行动时手牌仍保持清晰可读。

手机端采用固定一屏布局：顶部显示双方声望、回合和牌库；中间同时保留五种兵器入口，点击切换当前配方；底部两行展示手牌，并固定显示重铸与回合按钮。手牌超限到9张时切为5列两行，仍可直接选择弃牌。对局记录、详细配方和卡牌说明可点开查看。横屏手机采用造兵区与手牌区左右并排布局，并适配动态视口高度与安全区域。

攻击包含箭矢、连弩、铳火、炮弹与雷阵表现，命中后出现墨色冲击、金色碎光、伤害数字和工坊受击反馈。特效位于屏幕层，滚动到手牌区后也能看到。炸炉止损与胜负弹窗会在特效结束后出现。开启系统「减少动态效果」时，改为静态文字反馈。

## 文件

- `index.html`：游戏页面
- `style.css`：桌面与手机布局
- `game.js`：对战规则与AI
- `app.js`：页面交互与动画
- `effects.js`：兵器攻击与受击表现
- `polish.css`：手牌分区与战斗特效样式
- `mobile.css`：手机一屏对战与横屏布局
- `cards.css`：深青古金手牌与手机图片牌面
- `card-art.js`：十一种物品插图的图集映射
- `assets/card-items.png`：本地物品插画图集，无需外部图片服务

无需安装依赖或构建。使用静态HTTP服务器即可本地运行。
